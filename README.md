# G33
# Cybersecurity Breach at Tata Electronics: A Case Study

This repository contains the deliverables for our research case study on the 2026 Tata Electronics cybersecurity breach, focusing on data exfiltration, cyber extortion, and supply-chain risks. 

As this is a theoretical cybersecurity and policy analysis rather than a software development project, this repository serves as a portfolio of our research deliverables in lieu of source code or executable files.

## Repository Contents
* **Case_Study_Report.pdf**: The final research paper detailing the incident timeline, security impact analysis, and recommended countermeasures mapped to NIST and CERT-In frameworks.
* **Presentation_Slides.pptx**: Slide deck used for the project evaluation and defence.
* **Project_Video_Recording.mp4**: Group presentation recording discussing our findings.
* **Plagiarism_Report.pdf**: Originality check verifying the authenticity of our research.
* **AI_Similarity_Report.pdf**: AI-generation detection report.

## Methodology Overview
Our research methodology does not involve technical implementations or executable code. Instead, it relies on:
1. **Incident Identification & Timeline Construction:** Aggregating public reports to map the attack lifecycle from unauthorised access to data exfiltration.
2. **Cybersecurity Analysis:** Evaluating the breach's impact on confidentiality, integrity, and supply-chain dependencies.
3. **Framework Mapping:** Aligning the incident response and recommended security controls (e.g., Zero Trust Architecture, Data Loss Prevention) with the NIST Cybersecurity Framework 2.0 and CERT-In guidelines.
